# iOS Install Instructions — Project G-Code Tutorial

## Status
The current PWA is installable from the homepage link on iOS; manifest, service worker, and Apple web-app meta tags are present in the repo. One optional improvement is an `icons/icon-180.png` for the iOS home-screen icon.

## Recipient Instructions
Share these exact steps with anyone using Safari on an iPhone or iPad:

1. Open this link in Safari:
   `https://orangetrd-byte.github.io/Project-G-code-tutorial-/`
2. Tap the Share icon (box with arrow) at the bottom of the screen.
3. Scroll down and tap “Add to Home Screen.”
4. Confirm the name “G-Code,” and then tap “Add.”
5. The app icon now appears on the home screen; tap it to open full-screen.

## Notes
- The app runs offline after its first load.
- If the home-screen icon looks generic, add `icons/icon-180.png` and an Apple touch icon link in `index.html`.
